df_for_plots(result, features=None, use_exposure=False, only_test=False)[source]

Construct a dataframe with results for plotting.

This method creates a consolidated dataframe containing features, true values, predictions, and optionally exposure values. It also returns lists of categorical and numerical features.

Parameters:

  • result (DSManagerResult) – DSManagerResult object containing model predictions and data subsets

  • features (list, optional) – Specific features to include in the output dataframe. If None, all features are included. Default is None.

  • use_exposure (bool, optional) – Whether to include and apply exposure to predictions. Default is False.

  • only_test (bool, optional) – Whether to include only test data or both test and train data. Default is False (includes both).

Returns:

A tuple containing three elements: - pd.DataFrame: Consolidated dataframe with features, true values,

predictions, and optionally exposure

  • list: List of categorical feature names

  • list: List of numerical feature names

Return type:

tuple

Note:

If no categorical/numerical features exist, the corresponding lists will contain [‘No features’]

Note:

When use_exposure is True, predictions are multiplied by exposure values

Note:

Missing values in y_true and y_prediction are filled with 0
