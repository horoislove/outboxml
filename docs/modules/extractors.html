Extractors

“Module for dataset extraction.

class outboxml.extractors.Extractor(*params)[source]

Bases: ABC

Base interface for extracting data.

Abstract base class that defines the interface for data extraction. Inherited user classes should implement the extract_dataset method which returns a pandas or polars DataFrame.

Variables:

  • __connection_config – Internal connection configuration.

  • load_config_from_env – Whether to load configuration from environment.

  • connection_config – Connection configuration object.

Note

Subclasses must implement the extract_dataset() method.

Example:

class MyExtractor(Extractor):
    def extract_dataset(self) -> pd.DataFrame:
        # Your extraction logic here
        return pd.read_csv('data.csv')

class outboxml.extractors.SimpleExtractor(data, *params)[source]

Bases: Extractor

Simple extractor for pre-loaded data.

This extractor is used when data is already loaded into memory as a Pandas’ DataFrame or Polars’ DataFrame. It does not require any.

Parameters:

  • data (Pandas' DataFrame or Polars' DataFrame) – Pre-loaded dataset.

  • *params –

    Additional parameters (currently unused).

Example:

data = pd.read_csv('my_data.csv')
extractor = SimpleExtractor(data=data)
dataset = extractor.extract_dataset()

class outboxml.extractors.BaseExtractor(data_config)[source]

Bases: Extractor

Base class for extractor supporting multiple data sources.

Supports extraction from: - CSV files - Pickle files - Parquet files - Databases (PostgreSQL, etc.)

Parameters:

data_config (DataModelConfig) – Data configuration object specifying the data source and connection parameters.

Variables:

__data_config – Internal data configuration object.

Example:

from outboxml.core.pydantic_models import DataModelConfig

config = DataModelConfig(
    source="csv",
    local_name_source="data.csv"
)
extractor = BaseExtractor(data_config=config)
dataset = extractor.extract_dataset()
