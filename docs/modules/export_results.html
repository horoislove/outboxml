Export Results

class outboxml.export_results.ResultExport(ds_manager, ds_manager_to_compare=None, config=None)[source]

Bases: object

Main module for exporting and processing calculation and model results.

This class handles exporting and processing of model results, including metrics and plots. Can be used for model comparison and retrospective analysis.

Parameters:

  • ds_manager (DataSetsManager) – DataSetsManager object with results (after calling fit_models() method).

  • ds_manager_to_compare (DataSetsManager, optional) – Another DataSetsManager object with results for comparison. Defaults to None.

  • config (Any, optional) – External config file with passwords, logins, paths to save and folders. Uses .env by default if not provided.

Variables:

  • _ds_manager – DataSetsManager object with results.

  • result – Dictionary of results from ds_manager.

  • project_name – Name of the project.

  • _ds_manager_to_compare – Optional DataSetsManager for comparison.

  • result_to_compare – Optional results for comparison.

  • project_name_to_compare – Optional project name for comparison.

Examples

from outboxml.datasets_manager import DataSetsManager
from outboxml.export_results import ResultExport

# After training models
ds_manager = DataSetsManager(config_name="config.json")
ds_manager.fit_models()

# Export results
exporter = ResultExport(ds_manager=ds_manager)
exporter.save(to_pickle=True, to_mlflow=True)

load_data_to_db()[source]

Load data to Grafana database using parameters from external config.

This method appends the DataFrame data to the specified table in the database. If the table doesn’t exist, it will be created automatically.

Warning

Uses if_exists=’append’ which will add data to existing tables without clearing previous data. Consider table size implications.

Returns:

None

Return type:

None

Raises:

  • sqlalchemy.exc.SQLAlchemyError – If database operation fails

  • ValueError – If DataFrame contains unsupported data types

  • Exception – For other unexpected errors during database operations

Example

>>> df = pd.DataFrame({'metric': [1, 2, 3], 'value': [10, 20, 30]})
>>> exporter = GrafanaExport(df, table_name='metrics')
>>> exporter.load_data_to_db()
Data loaded successfully
