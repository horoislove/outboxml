  • y (Series) – Target values.

  • type (str) – The feature’s type, numerical and categorical are supported.

  • name (str) – The feature’s name.

Prepare dataset. Input data should be Pandas’ or Polars’ DataFrame or dict of feature and value pairs.

Parameters:

  • group_name (str) – Models’ group name.

  • data (Dict | DataFrame | DataFrame) – Input data.

  • train_ind (Index | None) – Indices of training subset.

  • test_ind (Index | None) – Indices of testing subset. (Deprecated)

  • model_config (ModelConfig) – Model’s config.

  • check_prepared (bool) – Whether to check prepared dataset.

  • calc_corr (bool) – Whether to calculate correlation matrix. (Deprecated)

  • save_data (bool) – Whether to save prepared dataset.

  • corr_threshold (float | None) – Threshold for correlation matrix. (Deprecated)

  • target (Series | DataFrame | None) – Target’s values.

  • log (bool) – Whether to log the process.

  • modify_dtypes (bool) – Whether to modify dtypes to int32, float32 and category respectively.

  • raise_on_encoding_error (bool) – Whether to raise if an encoding error occurs.

  • extra_columns_list (List[str] | None) – List of extra columns to be added to the dataset (for Polars only).

Returns:
