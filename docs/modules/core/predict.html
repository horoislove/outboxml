Prediction

Module for calculating model predictions.

async outboxml.core.predict.ensemble_predict(ensemble_name, ensemble, features_values, log=True, modify_dtypes=True, raise_on_encoding_error=True)[source]

Predict ensemble models.

Parameters:

  • ensemble_name (str) – Ensemble name.

  • ensemble (dict, EnsembleResult.) – Object of models ensemble.

  • features_values (dict, list[dict], pandas.DataFrame) – Data for ensemble models.

  • log (bool) – Flag for logging.

  • modify_dtypes (bool) – Modify data columns types during data preparation.

  • raise_on_encoding_error (bool)

Return type:

Dict

:param Flag for raising exception on encoding error. :type raise_on_encoding_error: bool :return: Predictions, data, model info. :rtype: dict :raises TypeError: Invalid features_values type. :raises NotImplementedError: Invalid ensemble: imprecise conditions.

Example

features_values = [{

‘FEATURE1’: 100, ‘FEATIRE2’: 200, ‘CHANNEL’: ‘RETAIL’

}]

predictions = ensemble_predict(

ensemble_name=’titanic’, ensemble=’titanic_channel’, features_values=features_values, log=False, modify_dtypes=False, raise_on_encoding_error=True

)

outboxml.core.predict.one_model_predict(group_name, model_result, features_values, log=True, modify_dtypes=True, raise_on_encoding_error=True)[source]

Predict simple models.

Parameters:

  • group_name (str) – Model group name.

  • model_result (dict, DSManagerResult.) – Object with model result.

  • features_values (dict, pandas.DataFrame) – Data for ensemble models.

  • log (bool) – Flag for logging.

  • modify_dtypes (bool) – Modify data columns types during data preparation.

  • raise_on_encoding_error (bool)

Return type:

Dict

:param Flag for raising exception on encoding error. :type raise_on_encoding_error: bool :return: Predictions, data, model info. :rtype: dict :raises TypeError: Invalid features_values type.

Example

model_result = {
‘model_config’: {

‘name’: ‘first’, ‘column_target’: ‘TARGET’, ‘objective’: ‘poisson’, ‘wrapper’: ‘catboost’, ‘features’: [

{

‘name’: ‘FEATURE1’, ‘default’: 0, ‘replace’: {‘_TYPE_’: ‘_NUM_’}

}, {

‘name’: ‘FEATURE2’, ‘default’: 1, ‘replace’: {‘_TYPE_’: ‘_NUM_’}

}

]

}, ‘model’: titanic_catboost, ‘features_numerical’: [‘FEATURE1’, ‘FEATURE2’], ‘features_categorical’: []

}

features_values = {

‘FEATURE1’: 100, ‘FEATIRE2’: 200

}

predictions = one_model_predict(

group_name=’titanic’, model_result=’titanic_first’, features_values=features_values, log=False, modify_dtypes=False, raise_on_encoding_error=True

)
