Data Subsets

This module provides classes for managing prepared datasets, feature metadata, and data preprocessing pipelines.

ModelDataSubset

Container for prepared datasets, targets, exposures, and feature metadata.

class outboxml.data_subsets.ModelDataSubset(model_name, X_train=Empty DataFrame Columns: [] Index: [], y_train=Series([], dtype: object), X_test=None, y_test=None, features_numerical=[], features_categorical=[], X=None, exposure_train=None, exposure_test=None, sample_weight_train=None, sample_weight_test=None, extra_columns=None)[source]

Bases: object

Container for prepared datasets, targets, exposures, and feature metadata.

Stores train/test splits, feature lists, optional full X matrix, exposure series, and any extra columns. Provides helpers to construct subsets from pandas or polars data, combine two subsets, and drop columns.

Parameters:

  • model_name (str) – Name of the model the subset belongs to.

  • X_train (pandas.DataFrame) – Training feature matrix.

  • y_train (pandas.Series) – Training target series.

  • X_test (pandas.DataFrame, optional) – Test feature matrix, if available.

  • y_test (pandas.Series, optional) – Test target series, if available.

  • features_numerical (list[str], optional) – List of numerical feature names.

  • features_categorical (list[str], optional) – List of categorical feature names.

  • X (pandas.DataFrame, optional) – Full feature matrix (unsplit), if stored.

  • exposure_train (pandas.Series, optional) – Training exposure (weights), if any.

  • exposure_test (pandas.Series, optional) – Test exposure (weights), if any.

  • extra_columns (pandas.DataFrame, optional) – Optional DataFrame of extra columns to carry along.

  • sample_weight_train (Series | None)

  • sample_weight_test (Series | None)

Examples

import pandas as pd
from outboxml.core.prepared_datasets import PrepareDataset

# Direct construction
subset = ModelDataSubset(
    model_name="my_model",
    X_train=pd.DataFrame({"f1":[1,2]}),
    y_train=pd.Series([0.1, 0.2], name="target"),
    X_test=pd.DataFrame({"f1":[3]}),
    y_test=pd.Series([0.3], name="target"),
    features_numerical=["f1"],
    features_categorical=[]
)

# Combine two subsets (features concatenated, targets taken from left)
combined = subset + subset

# Drop columns in-place and keep feature lists in sync
ModelDataSubset.drop_columns(combined, ["f1"])

DataPreprocessor

High-level data preprocessor that prepares and persists model subsets.

class outboxml.data_subsets.DataPreprocessor(prepare_dataset_interface_dict, dataset, data_config, version='1', prepare_engine='pandas', external_config=None, use_saved_files=False, retro=False)[source]

Bases: object

High-level data preprocessor that prepares and persists model subsets.

Handles: - Train/test splitting via TrainTestIndexes or TrainTestIndexesPl - Delegating feature preparation to PrepareDataset / PrepareDatasetPl - Optional exposure weighting of the target - Persisting intermediate datasets to Parquet and subsets to pickle - Loading subsets for multiple models

Parameters:

  • prepare_dataset_interface_dict (dict[str, PrepareDataset | PrepareDatasetPl]) – Mapping of model_name to preparation interface (pandas or polars).

  • dataset (pandas.DataFrame or Extractor) – Raw dataset or an Extractor implementation.

  • data_config (DataModelConfig) – Data configuration with separation settings and extras.

  • version (str, optional) – Version string used in filenames. Defaults to ‘1’.

  • prepare_engine (Literal['pandas', 'polars'], optional) – Engine to use (‘pandas’ or ‘polars’). Defaults to ‘pandas’.

  • external_config (object, optional) – External config with results_path. Defaults to None.

  • use_saved_files (bool, optional) – If True, reuse existing pickled subsets. Defaults to False.

  • retro (bool, optional) – If True, keep full columns when saving dataset for retro analysis. Defaults to False.

Variables:

  • model_names – List of model names to process.

  • index_train – Cached training index after preparation.

  • index_test – Cached test index after preparation.

Examples

# Assume you have:
# - data_config: DataModelConfig
# - df: pandas.DataFrame with all required columns
# - pd_interface: an instance implementing PrepareDataset for pandas
#
# Basic pandas flow
p = DataPreprocessor(
    prepare_dataset_interface_dict={"my_model": pd_interface},
    dataset=df,
    data_config=data_config,
    version="1",
    prepare_engine="pandas",
    use_saved_files=False,
)
subset = p.get_subset("my_model")  # prepares, saves, and loads from pickle

# Access all subsets for all configured models
all_subsets = p.data_subsets()

# Polars flow (if you have a polars PrepareDatasetPl)
# polars_interface: PrepareDatasetPl
p_pl = DataPreprocessor(
    prepare_dataset_interface_dict={"my_model_pl": polars_interface},
    dataset=pl.DataFrame(df),  # or a real polars DataFrame
    data_config=data_config,
    version="1",
    prepare_engine="polars",
)
subset_pl = p_pl.get_subset("my_model_pl")
